How to run OpenSnick on your Mac

1

Build or Download

Run ./build.sh in the project directory, or run ./install.sh to copy Snick.app directly to your /Applications folder.

2

Launch Snick

Launch Snick.app. It resides exclusively in your menu bar with a discreet icon and zero dock clutter.

3

Grant Accessibility

Open System Settings → Privacy & Security → Accessibility and enable Snick. macOS requires this to receive global scroll wheel events.

4

Scroll & Enjoy

Every scroll across Safari, Chrome, Finder, Slack, or Xcode now responds with buttery tactile detents!

Frequently Asked Questions

What makes this an open-source version of Snick?

Snick (trysnick.xyz) is a commercial macOS app sold on LemonSqueezy. This project is a 100% free, MIT-licensed open-source reimplementation written natively in Swift/SwiftUI and AppKit. All 7 sound files (Nok, Vyl, Glu, Dib, Plo, Tok, Rub) were extracted directly from the web client.

Why is Accessibility permission required on macOS?

macOS only delivers global system-wide scroll events (from other apps) to utilities that have Accessibility permissions. OpenSnick never inspects your content or keystrokes and runs entirely offline with zero network connectivity.

Does it support notched mouse wheels too?

Yes! In addition to continuous trackpad scrolling, OpenSnick features a Stepped Mouse Wheel mode that clicks cleanly on every physical notch of an external mouse wheel.
