How to run Thock+ on your Mac

1

Build or Install

Run ./install.sh in the project directory to compile and install Thock+.app directly into your Applications folder.

2

Launch Thock+

Look for the T+ icon in your menu bar. Zero dock clutter, runs quietly in the background.

3

Grant Accessibility

Open System Settings → Privacy & Security → Accessibility and enable Thock+. Required for global scroll & key event detection.

4

Enjoy Every Stroke & Scroll

Every keystroke, click, and scroll wheel notch now responds with buttery mechanical sound and physical trackpad oscillation!
